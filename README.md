# 🚀 Evolução em Programação Orientada a Objetos (POO)

Este repositório documenta a minha jornada prática no aprendizado e aplicação de Programação Orientada a Objetos utilizando Python. 

## 📈 Trilha de Aprendizado

*   **Fundamentos**
    *   Criação de classes e métodos construtores (`__init__`).
    *   Definição de atributos básicos.
    *   Instanciação simples de objetos.

*   **Segurança e Estruturação de Dados (Fase Atual)**
    *   **Encapsulamento:** Proteção de dados utilizando convenções de atributos privados (ex: `self._id`, `self._salary`).
    *   **Acesso Controlado:** Uso do decorator `@property` (Getters) para leitura segura de atributos.
    *   **Armazenamento e Iteração:** Manipulação de múltiplos objetos organizados dentro de Listas e iteração direta em memória.
    *   **Regras de Negócio:** Implementação de métodos internos na classe para lidar com lógicas específicas (ex: aumento de salário, formatação com `__str__`).
